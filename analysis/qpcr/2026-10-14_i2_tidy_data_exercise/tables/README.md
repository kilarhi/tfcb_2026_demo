## What Happened

I reformatted `tidy_data_exercise.xlsx` into a tidy table in Excel. 
Both plates (4 and 7) were combined into a single table with 108 rows, 
one per well, using the columns: plate, well, amplicon, sgrna, treatment, 
cq, and note. Grouped amplicon and sgRNA labels were filled into each 
corresponding row. Well numbering follows the original: Plate 4 uses 
columns 1–9 and Plate 7 uses columns 2–10. Well F07 on Plate 7 is flagged 
as an outlier in the note column but kept in the table. Cq values are 
unmodified.
